英語のつづりが出てこなくても、止まらなくていい。 I like サッカー でも I like sakkaa でも通じます。 相手が soccer と言い直して返してくれるので、それを見て次から使えばいい。 まちがいは指摘されません。

① 相手を呼び出す

コピーしてAIにはると、グアテマラの中学生が出てきます。別のタブで開いたまま、この画面の手札を見ながら話します。
2画面にするには。「右半分にAIをひらく」を押したあと、この画面を左半分に寄せます。
Windows … この窓をつかんで画面の左はしまでドラッグ（または Windowsキー＋←）／ Chromebook … 最大化ボタンを長おしして左を選ぶ／ iPad … AIのタブを下のバーから横へドラッグ（Split View）
AIモードはこのページの中には入れられません（Googleが埋め込みを止めているため）。 窓を2つ並べるのが、いちばん確実です。
プロンプトを見る

② おわったら、ふりかえる

AIに finish（または おわり）と送ると、自分が言った文だけが並んで出てきます。 それをぜんぶコピーして、ここにはります。数えるのはこのアプリです。AIには数えさせません。

③ ふりかえり

数え方（ぜんぶ機械で数えています。初期値・要調整）
話した量＝自分の文にある英語の語とカタカナ語の数。多ければよい、ではありません。ほとんど0でないかを見るだけ。
中身のある語＝I / is / the / like / Really? などを除いた、ちがう語の数（同じ語は1回）。カタカナ語も数えます。
質問したターン＝? でおわる文、または Do / What / How などで始まる文があるターンの数。率＝それ ÷ 全ターン。 Really? だけの文は あいづちなので数えません。
2文以上のターン＝1回の発言に文が2つ以上あった回数。
次の一手＝質問の率 30%未満 → 2文以上の率 30%未満 → 中身のある語 8未満、の順に見て、最初に当てはまったもの1つ。
この数は成績と関係ありません。記録も送信もしていません。
楽しかったかどうかは、測っていません。それはここに出ていない、いちばん大事なことです。
点はつけません。記録もしません。送信もしません。ページを閉じると消えます。
手札を見るのは、ずるではありません。見ながらでも止まらなければ、それが今日の勝ちです。
AIはまちがいを直しません。通じればいい、という練習です。
